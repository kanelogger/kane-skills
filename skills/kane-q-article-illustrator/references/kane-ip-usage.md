# Kane Q Asset Usage

Read this reference only when an illustration includes Kane Q.

## Reference Selection

- Use `assets/kane-q/three-view.png` as the main identity reference.
- Use `assets/kane-q/front-full-body.png` when a simple frontal full-body reference is sufficient.
- Add at most one expression image when its pose or emotion helps the target scene:
  - `01-v-sign.png`: opening, confidence, lightness
  - `02-reading.png`: reading, learning
  - `03-thinking.png`: analysis, reflection
  - `04-thumbs-up.png`: approval, recommendation
  - `05-coffee.png`: pause, recovery
  - `06-work-ready.png`: writing, execution
  - `07-shrug.png`: ambiguity, tradeoff
  - `08-starting.png`: launch, next action

Reference images establish identity. They do not limit the scene to an existing pose, emotion, crop, background, prop, or group composition.

## Compact Character Cue

Depict Kane Q as a chibi adult male with a large head and small body, short black hair, black square-rounded glasses, and a relaxed, intelligent expression. His familiar outfit is a white short-sleeve T-shirt with a small left-chest `Kane.` mark, dark casual pants, and light sneakers. Preserve enough of these cues to keep him recognizable while adapting the illustration style and scene to the article.
