# 按 JD 配准简历

输入优先包括目标 JD、现有简历或经历事实、目标语言与格式。缺 JD 时可以先做通用诊断，并说明哪些匹配判断无法完成。默认保留原件，交付可编辑的改稿和修改说明；用户指定格式时遵循其要求。

## 编写

1. 将 JD 分为硬性条件与加分项，并从中提取“岗位技能、行为要求、结果目标”三类词。按出现位置、重复程度和职责重要性暂定权重；词频不能单独决定权重。
2. 对每个核心要求找经历证据。写出“JD 原文 → 用户事实 → 拟用表述 → 简历位置”；缺证据的要求列为差距，不硬塞关键词。对转岗经历只翻译真实动作，不把旧职位改成新职位。可读 [改写样例](references/resume-rewrite-example.md)。ATS 的规则因系统和设置而异，不能承诺通过机筛。
3. 首屏让读者快速看到目标角色、相关年限、最强的两三项证据。摘要仅在确实有帮助时写，不强制约 200 字，也不写无法核验的人格保证。
4. 经历用倒序、清楚的时间和岗位信息。优先描述本人动作及结果；量化时保留基准、周期和口径。可用真实场景和转折说明解决问题的方式，不为“活人感”编情节。
5. 按岗位删减无关细节，保留重大时间事实。跨方向可做多个版本，但每版事实一致。

## 校验

检查事实、时间线、岗位名称、学历、雇佣关系、数字与来源是否一致；重新计算百分比，并核对分子、分母及周期。不要虚构工作经历、薪资或公司证明。简历内容避免泄露身份证号、家庭信息和雇主机密。格式用清晰标题与常规文本结构，避免复杂表格、图片承载正文；具体投递格式以招聘方要求为准，PDF 与可编辑版按需准备。背景核验范围和法律后果因地区及雇主而异，不作未经证实的断言。

交付完整简历或可直接替换的段落，并附简短差距表：已匹配要求、缺证据要求、待用户核对事实。用户只要求诊断时先给最影响结果的修改点，不强行重写。
