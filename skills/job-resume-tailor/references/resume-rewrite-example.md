# 简历改写的证据链

以下人物、JD 和经历均为虚构的教学数据，用于展示改写方法；不要作为真实用户履历输出。

目标 JD：内容运营，要求活动策划、用户沟通、数据复盘，以参与率和留存衡量效果。

用户原始事实：在行政岗位组织过一次员工活动；负责报名表、会场协调和会后问卷。报名 80 人，到场 64 人；没有后续留存数据。

| JD 要求 | 原始表述 | 可用改写 | 边界 |
|---|---|---|---|
| 活动策划、用户沟通 | “负责公司团建” | “协调报名、场地与活动通知，组织 80 人报名的员工活动，实际到场 64 人” | 这是内部员工活动，不改称外部用户增长项目 |
| 数据复盘 | “活动效果良好” | “整理报名与到场数据，并汇总会后问卷反馈；到场率 64/80＝80%” | 若问卷没有记录，就删去问卷；到场率不能写成留存率 |
| 留存 | 无 | 列入证据缺口 | 不杜撰留存提升 |

改写前先核对“80”“64”和问卷是否有原始记录。若用户只记得大致人数，改成“约”并标待核对；不计算看似精确的百分比。摘要可突出协调和复盘能力，但不冒充正式运营岗位经历。

方法来源：`为啥简历被秒挂？ATS机筛系统规则揭秘`（2025-09-16）与`转行简历的写法附参考模版`（2025-10-23）。本例的 JD 与人数是专为教学构造的，不来自这两份素材。
