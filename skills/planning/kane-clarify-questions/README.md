# kane-clarify-questions · 提问完善

通过少量具体问题补齐任务上下文，避免问得太宽、问得太多，或问完没有使用答案。适合写作、研究、活动策划和日常工作中目标、受众、约束或交付要求尚不明确的任务。

## 使用

将包含 [SKILL.md](SKILL.md) 的整个目录复制或安装到支持 Agent Skills 的运行时。无需脚本、API 或额外依赖；优先使用运行时可调用的用户输入工具，没有可用工具时以编号文本提问。

仅在用户点名时启用。在 Codex 中输入 `$kane-clarify-questions`，并说明当前任务；已有对话、材料和限制可直接复用，无需先填一份固定问卷。

```text
使用 $kane-clarify-questions，帮我补全这项任务的上下文：
我想给新同事做一次知识管理分享，目前只有几篇读书笔记。
先问会影响分享内容的问题，再整理成后续写讲稿可用的依据。
```

如果希望补全后继续执行，在请求中一并说明，例如「补全上下文后，继续写讲稿提纲」。

## 使用体验

- **会问什么**：只补会影响产出的关键缺口，复用已有信息；信息充分时不提问。需要看过内容才能选择时，可用简短对照样例帮助判断。
- **会问多久**：默认最多两轮，每轮最多五题，样例反馈也算在内。未给任务时先定位一次任务，不占澄清轮次；主动说「继续问」可追加一轮，也可指定数量。
- **如何回答**：可以选择、自由填写、跳过或说「你定」。代定内容会标为假设，未知事实不会被编造；纯文本提问可直接回复「1A 2C 3：下周五」。
- **得到什么**：任务目标及「已确认事实／采用的假设／仍未确定的事项」，说明对下一步的影响；待验证事项附最小验证动作。默认在对话中交付，指定位置时才另存文件。

## 边界

只要求补全上下文时，整理完成即结束；原请求同时授权后续任务时，继续推进可执行部分。需要额外制作原型或实测、且原请求未授权时，只交接验证需求。材料读取使用现成只读能力，不另行下载远程文件。

本技能不承担完整的软件需求文档访谈，也不负责已有文稿的语言润色；适用范围是通用任务的上下文补全。
