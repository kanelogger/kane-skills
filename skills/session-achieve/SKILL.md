# Session Achieve

把一次多轮协作整理为可核查的复盘资产。报告以会话中的可见证据为准，区分事实、推断与未知，不为填满模板而编造问题、偏好或精确分数。

## 先确定复盘范围

- 默认复盘当前上下文中可见的完整会话。
- 用户指定片段、目标或时间范围时，只复盘该范围。
- 上下文可能被截断或压缩时，在报告开头说明证据边界；不要声称看过不可见轮次。
- 请求只是“总结内容”时直接总结，不启用本技能。请求是改写提示词时交给提示词优化流程，不生成会话复盘。
- 只有范围不清会实质改变结论时才追问；否则采用最窄的合理范围并明确写入报告。

## 复盘方法

### 1. 建立事实时间线

从可见会话中提取：

1. 用户的初始目标，以及后来明确批准的目标变化；
2. 已交付、已验证、未完成和失败的结果；
3. 用户纠正、工具或测试失败、重新决策等关键转折；
4. 仍需用户确认或缺少证据的事项。

引用应能定位，例如“用户第 4 轮”“工具输出：测试 X 失败”或具体产物路径。若界面没有稳定轮次编号，使用简短事件描述，不虚构编号。

### 2. 评价达成情况

优先使用用户定义的成功标准、测试结果、日志、产物状态和明确反馈。给出以下结论之一：

- 已达成
- 部分达成
- 未达成
- 无法判断

百分比只在存在可解释的评分项或用户明确要求量化时使用，并列出计算依据。没有可靠分母时不要给伪精确数字。

### 3. 提炼纠偏

只记录改变了方向、约束、实现或验收结果的纠偏。每条说明：

- 证据位置；
- 原偏差或失败；
- 用户/系统提供的新约束；
- 实际调整；
- 调整后的结果或当前状态。

礼貌回应、未证实的心理动机和模型自己的猜测不算纠偏证据。

### 4. 区分约束层级

- **明确约束**：用户直接陈述，或项目规则明确要求。
- **推断偏好**：至少有具体行为证据支持；标注证据与置信度。
- **未知项**：信息不足、证据冲突或尚未验证的内容。

一次性要求不得自动上升为长期偏好。没有足够证据时写“未发现可可靠推断的偏好”。

### 5. 判断是否生成可复用提示词

只有当本次任务可能重复，且纠偏经验能转化为稳定输入、约束或验收标准时，才生成“下次可复用提示词”。提示词必须：

- 保留本次目标与明确约束；
- 把验证方式和停止条件写清楚；
- 用变量标记仍需替换的上下文；
- 不把一次性路径、临时故障或未经确认的偏好固化为通用规则。

若复用价值不足，写明“不生成：本次任务高度一次性/证据不足”，不要强行产出所谓完美提示词。

## 生成报告

读取 [assets/achieved_template.md](assets/achieved_template.md)，在用户指定位置或当前工作目录生成：

```text
achieved-YYYYMMDD-HHMMSS.md
```

文件名使用运行环境的本地时间。目标文件已存在时追加 `-2`、`-3`，除非用户明确要求覆盖。报告至少包含：范围、目标与结果、达成评价、证据与纠偏、约束层级、未知项、可复用提示词判断和总结。

可直接填写模板。需要稳定地批量渲染时，先按 [references/review-data-schema.md](references/review-data-schema.md) 准备 JSON，再运行：

```bash
node scripts/generate-review.js --data review-data.json
```

仅在不确定内容密度或措辞标准时读取 [references/few_shot_example.md](references/few_shot_example.md)。

## 项目进化集成

仅当 `project-skill-evolver` 明确调用本技能时，才生成 Signal：

1. 先读 `../project-skill-evolver/references/contracts.md` 的 Signal v1 契约；
2. 一个 Signal 只描述一个可观察问题；
3. `evidence.ref` 必须定位到真实会话、复盘条目或已执行 Trace；
4. `target_skill` 必须明确且符合契约；无法确定时不生成 Signal，并把该项留在复盘的“未知与待确认”中；
5. 没有用户纠正、可复现失败或人工确认时，不生成 Signal。

普通复盘不得生成 Signal 或修改项目进化状态。

## 交付

生成后告诉用户：报告路径、复盘范围，以及是否存在需要确认的未知项。保持简短，不重复粘贴整份报告。

## 交付前检查

- 范围与可见性限制已写明；
- 每个关键判断都有证据或被标为推断/未知；
- 达成结论来自验收证据，百分比没有伪精确；
- 未强制制造错误、偏好或可复用提示词；
- 文件名和输出位置正确，未静默覆盖现有文件；
- 集成模式下的 Signal 满足当前契约，普通模式下没有 Signal。
