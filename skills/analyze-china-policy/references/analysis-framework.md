## 使用原则

分别判断三个轴，不计算总分。等级只用于同一分析中的结构化表达，不能替代正式法律位阶，也不能机械比较不同政策领域。

## 约束强度 `constraint`

| 等级 | 判定线索 |
| --- | --- |
| C0 | 新闻、说明、倡议或目标陈述，没有可识别的行为要求 |
| C1 | 鼓励、支持、引导等方向性要求，适用主体或后果不明确 |
| C2 | 明确责任或条件，但仍依赖授权、配套规则或地方承接 |
| C3 | 主管机关在权限内给出明确对象、行为、条件和生效安排 |
| C4 | 现行法律法规或成熟监管规则提供清晰义务、禁止、程序及法律后果 |

先写明正式文件类别和适用主体，再给 C 等级。存在权限争议、效力冲突或文本不完整时使用 `unknown`。

## 战略信号 `strategy`

| 等级 | 判定线索 |
| --- | --- |
| S0 | 单次表态，缺少正式部署或连续证据 |
| S1 | 局部试点或窄领域探索，方向仍可快速调整 |
| S2 | 主管部门或地方形成明确的中期部署 |
| S3 | 全国性、跨部门或重要年度任务，资源协调范围较大 |
| S4 | 经高层决策程序形成的长期安排，并在多个周期持续出现 |

战略等级必须相对于文件适用范围解释。地方长期战略可以在当地得到高等级，不能因地域范围直接降级。

## 执行强度 `execution`

| 等级 | 判定线索 |
| --- | --- |
| E0 | 只有愿景、原则或研究任务 |
| E1 | 确定方向和责任部门，但缺少工具、期限或资源 |
| E2 | 已给出工具、试点或实施路径，关键配套尚未完成 |
| E3 | 责任单位、时间表、量化指标、预算或办理流程较完整 |
| E4 | 已生效并有资金下达、执法、采购、申报、考核或公开执行结果 |

不要把预算目标当作实际支出，也不要把“制定细则”当作细则已经落地。

执行等级默认评价文件发布时的制度设计。需要评价当前落地时，另列 `execution_as_of_YYYY-MM-DD`，根据资金下达、申报、执法、采购、考核和公开结果重新判断；保留文件本体原等级。

## 影响地图

不用单一分数，记录四类标签：

- `scope`：全国 / 地方 / 试点 / 行业 / 特定主体；
- `horizon`：立即 / 当年 / 1–3 年 / 3–10 年；
- `mechanism`：监管 / 财政 / 税收 / 货币 / 信贷 / 土地 / 采购 / 人才 / 信息披露；
- `dependency`：预算、细则、地方承接、审批、技术、执法、需求或其他前置条件。

影响推理至少包含一条可检验链：

`措施 → 直接对象的行为变化 → 成本/收入/权利义务变化 → 可观察指标`

## 证据要求

每个等级至少引用一处原文，并写出限制条件。动词只提供线索：

- “必须、不得、应当”通常提示约束，但仍需核对主体、权限和例外；
- “确保、完成、落实”通常提示更强执行意图；
- “推动、支持、鼓励”通常保留裁量；
- “研究、探索、适时”通常表示条件或方案尚未确定。

措辞变化必须结合段落位置、发布机关、政策背景和配套措施解释。单个词变化不足以证明政策转向。
