# Analyze China Policy：中国政策文件分析 Skill

这是一个以官方原文为证据的中国政策分析工作流。它先核验文件身份和现行状态，再分别判断约束强度、战略信号和执行强度，最后解释影响范围、时间尺度与落地条件。

## 适合处理

- 判断一份政策的性质、效力、适用对象和“含金量”
- 比较相邻规划、会议通稿或实施文件的措辞变化
- 追踪预算、税收、信贷、采购、试点和监管措施如何落地
- 分析政策对行业、地区、企业或个人的直接与间接影响
- 建立后续配套文件、时间节点和验证指标清单

## 核心原则

- 官方原文优先，新闻转述不能替代正式文件。
- 法律约束、战略信号和执行强度分别判断，不计算总分。
- 文件标题不能直接决定效力，地方范围也不代表影响弱。
- 政策目标、执行措施和结果预测必须分开。
- 政策证据不能单独支撑证券买卖建议。

## 使用示例

- `分析这份低空经济政策的效力、执行强度和影响期限。`
- `比较今年和去年的会议通稿，哪些表述被强化或删除？`
- `这项地方监管办法对我所在企业有哪些直接义务？`
- `新闻说这是重大利好，请找到官方原文并判断是否已经落地。`
