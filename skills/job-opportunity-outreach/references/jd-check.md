# JD 与公司核查表

每一项都先抄原文，再写假设与核实结果。疑点是待确认信息，不是公司违规或欺骗的结论。

| 信号 | 向招聘方核查 | 交叉验证 |
|---|---|---|
| “综合薪资”“底薪＋提成” | 固定工资、无责底薪、提成条件、发放周期分别是多少？ | 书面薪酬条款、同类岗位公开区间 |
| 岗位名称与职责不一致 | 实际一周主要做什么？是否有销售或招聘指标？ | 同公司其他在招岗位、后续面试回答 |
| 职责跨多个职能且边界不清 | 哪些任务由本人负责，团队有哪些支持，优先级谁定？ | 团队结构、汇报对象与绩效标准 |
| 加班或时区要求模糊 | 常见工作时段、值班频率、补偿安排是什么？ | 招聘方书面说明与多方反馈 |
| “有无经验均可”同时要求复杂 | 培训时长、独立上岗标准、试用期目标是什么？ | 实际考核流程与劳动条件 |
| 长期反复发布或催促入职 | 是新增岗位还是替补？预计招聘人数和到岗原因是什么？ | 招聘历史、团队规模、多个来源 |
| 提前收费或索取敏感材料 | 费用用途、收款方、材料使用和保存方式是什么？ | 官方招聘入口；核实前暂停支付或提交 |

每条判断记录来源、取得日期、证据形式和仍待确认的条件，不用单个 A–D 等级混合不同证据。薪酬尤其要分开：

| 薪酬信息形式 | 记录方式 |
|---|---|
| 录用文件或其他正式书面条款 | 摘录固定与浮动部分、适用条件及尚未明确的项目；只把文件明确写到的内容列为书面待遇 |
| 招聘方邮件、聊天等书面说明 | 记录原文，标为“待与正式书面条款核对” |
| 招聘方电话或面谈中的口头答复 | 记录答复人、日期和具体说法，标为“待书面确认” |
| 第三方反馈、公开区间或仅凭 JD 措辞推断 | 只作为核查线索，不当作该岗位的已确认待遇 |

直接观察可以支持“当天看到的办公情况”等观察事实，不能升级成薪酬、长期工时或公司财务状况的直接证据。多来源说法一致会增加核查价值，但仍要保留各自的证据形式。

原始案例里，一份传媒招聘称“底薪 6000”，当事人入职后反馈固定底薪另有构成且日常工作偏电话销售。这个案例说明要核对工资构成与工作任务；它不能推出所有强调福利或底薪加提成的岗位都相同。其他仅靠 JD 语言推算工资或工时的案例，保留为核查假设。

素材来源：`拆解一个传媒行业的岗位`（2024-07-21）、`拆解一个国企招聘的JD`（2024-06-21）、`如何识破小缅北`（2026-04-07）。其中个别实地技巧涉及冒充身份或借口进入办公区，未纳入本技能。
