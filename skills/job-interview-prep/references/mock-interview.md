# 模拟面试问题地图

按目标岗位选题，不把下列顺序当真实公司的固定流程。一次只问一题，等用户答完再追问；用户说“先给提纲”时直接提供提纲。

## 校招

自我介绍 → 专业与岗位的关系 → 最有成就感的项目 → 最难的问题及本人处理 → 选择该岗位的原因 → 未来学习方向 → 工作时间与薪资期望 → 候选人反问。

校招可以使用课程、竞赛、实习、志愿服务或个人项目，但要区分课堂练习和真实业务成果。重点追问本人行动、反馈及从失败中学到的具体方法。

## 社招

自我介绍 → 最相关项目 → 困难与取舍 → 本人贡献和数据口径 → 跨团队协作 → 离职或转岗原因 → 薪酬与到岗安排 → 候选人反问。

资深或管理岗再追问：独立决策边界、资源配置、带人经历、结果归因、失败复盘。不能用团队成绩替代个人管理证据。

## 追问与反馈

- 数字：“这个结果的基准、周期和来源是什么？你控制了哪些变量？”
- 贡献：“这个决定是谁做的？若你不在场，结果会怎样变化？”
- 取舍：“当时放弃了哪个方案？为什么？”
- 一致性：“刚才说的是试点，简历为何写成正式上线？”

每轮反馈只写三项：回答中有证据的部分、最关键的缺口、下一次更清楚的说法。缺证据时建议承认边界，不代写虚假事实。

## 反问与谈薪

反问从面试已出现的线索出发，例如：“这个岗位前三个月最需要解决什么问题？”“刚才您提到跨部门协作，职责和决策权如何分配？”“这一岗位的固定薪酬、浮动条件和考核周期分别是什么？”

谈薪前列出现有与目标总报酬的构成、岗位级别、职责和用户底线。若用户要管理岗却没有带人经历，帮助他比较个人贡献岗与管理岗的条件，不劝他编造管理经历或默认接受降薪。
