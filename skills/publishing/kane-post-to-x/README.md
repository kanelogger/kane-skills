# kane-post-to-x

将已有内容准备成 X（Twitter）普通帖、图片或视频帖、引用帖，或把 Markdown 排版为 X Articles。可以先在本地查看，也可以在已登录的浏览器中组稿、保存草稿并交接发表。

在 Codex 中输入 `$kane-post-to-x` 显式调用。

| 内容 | 提供什么 | 得到什么 |
| --- | --- | --- |
| 普通帖、图片或视频帖 | 正文与有序本地附件 | 帖子预览或编辑器中的成稿 |
| 引用帖 | 目标 X 帖链接、评论及可选附件 | 核对过引用对象的成稿 |
| X Articles | Markdown 文件和可选封面 | 本地 HTML 预览、纯文本及图片清单，也可用来组稿 |

## 使用示例

- 「用 `kane-post-to-x` 把这段文字和两张图放到 X 草稿。」
- 「引用这条 X 帖，用我下面写好的评论，填好后交给我发表。」
- 「把 `essay.md` 排成 X Articles，只生成本地预览。」

本地文章预览需要 Bun 1.3.8 或更新版本，首次使用需安装技能目录内的脚本依赖。线上操作需要已登录的浏览器和当前账号的编辑权限，Articles 还需要相应的 X 订阅资格。远程图片先列入清单，使用认可的本地副本上传。用户在编辑器完成最终发表，技能随后核对发布链接。 [X Articles 帮助](https://help.x.com/en/using-x/articles)

将整个技能目录复制到 Agent 的技能目录即可使用。执行细节见 [SKILL.md](SKILL.md)。
