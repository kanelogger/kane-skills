# 浏览器投稿

## 打开正确的编辑器

1. 读取所选浏览器工具的用法和授权规则。在独立任务页打开微信公众平台 `https://mp.weixin.qq.com/`，核对实际登录的公众号名称。未登录或需要扫码时交给用户，登录后在同一个任务空间或会话继续核对账号。
2. 按页面当前显示的控件进入草稿箱或新建入口，选择「文章」或「贴图」（有些界面称「图文」）。点击前记下已打开的编辑器；点击后重新读取页面，选本次打开且编辑器已加载的页面。续做时核对账号、标题和草稿 ID 或内容特征，再决定是否复用。避免因编辑器出现较慢而再次新建。
3. 填写前确认没有误入既有草稿；后台可能自动保存。遇到帐号切换、借用标签页、重新登录或用户接管时，重新观察当前页面再继续。

## 填写与预览

### 文章

1. 从本地产物读取 `body.html`、`body.txt` 和 `meta.json`。填标题及用户提供或认可的作者、摘要、封面和阅读原文链接。摘要可采用本地生成的首段摘录；有长度限制时按后台提示处理。原创、留言、赞赏等设置依用户要求或沿用界面默认值。
2. 把正文以富文本粘贴到正文编辑器。ego-browser 在支持的平台可用文档中的 `page.keyboard.paste({ text, html })`，其中 `text` 和 `html` 分别是两个产物文件的 UTF-8 字符串。先定位已观察到的正文编辑区并确认焦点；用工具支持的文件读取传值，不把正文拼进 JavaScript 或 shell 源码。工具缺少富文本能力时请用户协助粘贴，或在用户接受纯文本后用 `body.txt`。
3. 在正文中按 `meta.json` 的 `images` 顺序逐一定位标记，用编辑器的插图入口上传对应 `file`，在预期位置看见图片后清除标记。检查正文中不再有标记、缺图或重复图片，封面单独设置。文件不存在、远程图还未落地或上传拒绝时说明具体图片，停止提交完整稿件。
4. 核对开头、中段和结尾，以及稿件中实际出现的标题层级、列表、表格、代码块和引注。后台可能改变样式。发现影响阅读的降级时先修正或交用户决定，再执行保存或发表。

### 贴图

1. 通过页面的图片控件上传本次清单中的图片。可以一次选多张时，仍以界面显示的排序为准；顺序不符就用界面重排。文件类型、大小和数量以当次校验为准。
2. 填写标题、配文和用户指定的字段，检查缩略图、实际顺序和文字。若首张图承担封面作用，核对预览中的首张。图片未上传完成时等待当前状态，出现失败再定位具体项。

## 写入与核验

| 用户要求 | 执行 | 完成证据 |
| --- | --- | --- |
| 保存草稿 | 点击保存为草稿 | 在目标账号的草稿箱或重新打开的同一草稿读回标题、正文或图片顺序；记录草稿 ID（可见时） |
| 正式发表或群发 | 复核账号、稿件及用户指定的发表动作，再用平台对应控件提交。平台需要扫码、安全验证或最终人工确认时由用户完成 | 查目标账号的记录。已发表附公开链接或对应发表记录；审核中单独报告提交状态 |

保存或发表后遇到超时、编辑页跳转、结果不明时，先按标题、当前操作时间和可见 ID 查草稿箱或发表记录。存在同名稿时核对内容，确认前不重复新建或提交。需要用户继续时保留任务页并按工具规则交接；结果确认后关闭本次创建的任务页或归还借用页。
