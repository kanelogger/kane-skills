# kane-q-cover-image

`kane-q-cover-image` 用来根据标题、文章、主题简报或视觉概念生成封面图，适用于文章、Newsletter、社交帖子、缩略图和页面 Hero。封面的构图、风格与人物使用由内容、受众和发布平台决定；需要人物时优先使用 Kane Q。

## 适用场景

- 为文章、公众号内容或 Newsletter 生成封面。
- 为社交平台生成缩略图或分享图。
- 根据标题或主题建立视觉隐喻和标题安全区。

## 输出

- 已保存的完整封面提示词。
- 经过全尺寸和缩略图检查的封面图片。

## 使用示例

```text
Use $kane-q-cover-image to create a WeChat article cover for this title:

AI Agent 正在改变内容生产方式
```

指定平台和比例：

```text
Use $kane-q-cover-image to create a 16:9 social cover from this article, with a clear title-safe area.
```
