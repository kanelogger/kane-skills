# kane-task-retro · 任务复盘

在一次任务或 Agent 协作结束时，先核对实际结果是否符合预期，再找最值得改的一处低效。适合核对交付效果、分析协作返工，或保留一次行之有效的做法。

## 用法

将包含 [SKILL.md](SKILL.md) 的整个目录复制或安装到支持 Agent Skills 的运行时。技能可以直接使用可见会话，也接受指定的会话片段、交付物、测试结果和验收记录。无需脚本或额外依赖。

```text
使用 $kane-task-retro 复盘刚才的任务，重点看哪里发生了返工。
```

```text
使用 $kane-task-retro，根据这段会话和附上的测试日志复盘任务，保存到 reports/retro.md。
```

## 产物

默认在对话中给出一张[复盘卡](assets/task-retro-card.md)，包括目标与实际结果、发现与证据、建议动作和下次验证。最多建议一个动作。发现有机会简化步骤或交付项时，卡片说明判断依据、预计能省下什么，以及下次如何按原标准验证效果。证据不足时标注待核实项。

已有证据指向同类问题时，卡片可给出一条排查或修复建议。你明确要求实施哪一项，再执行相应操作。只有任务会重复且经验可以复用时，才附提示词。

指定归档时会生成 Markdown 文件。未指定文件名时使用 `task-retro-YYYYMMDD.md`，同名时追加序号。代码审查、跨任务趋势和工程周报有各自的输入范围，不属于本技能的任务复盘。
