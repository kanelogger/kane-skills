# 停止本次任务启动的临时服务和后台任务

## 核对启动记录和当前实例

从本次任务的启动工具结果、命令或日志提取用途、工作目录和启动身份。临时服务、文件监听器、浏览器自动化实例、监控任务和后台脚本都适用。优先用能唯一标识当前实例的运行句柄、容器 ID 或工具任务 ID。只有 PID 时，把它与启动记录中的时间和当前进程启动时间、命令行及工作目录核对。端口只用于找监听者和验证退出。进程名称、端口、同一仓库路径或 PID 文件单独都不足以证明归属。

确认实例属于本次任务、用途已经结束，并且其他任务和交付物没有依赖它。保留借用的服务、用户已打开的浏览器、共享或生产实例及归属无法核实的进程。实例已经退出时，记录实际状态。若发现端口被另一个实例接管，把它作为独立对象保留。

## 停止并回读

1. 将已核实的实例标识、用途和停止方式纳入问题三。用户确认具体实例和动作后，动手前复核身份。优先用启动它的工具或服务管理器正常停止，操作范围限该实例。仅有经核实的本地 PID 时，对该 PID 发 `TERM`。
2. 短暂等待后回读实例状态。有监听端口时，核对原监听者已退出。遇到重启或遗留子进程时，核实归属和依赖，只有仍属于用户确认的对象和动作时才继续，否则报告为遗留实例。需要强制终止时，须有针对该实例的明确授权，并在执行前再次确认身份。
3. 汇报名称、实例标识和核验结果。确认退出后，才处理用户同时批准清理的 PID 文件或日志。只要求停止后台任务时保留相关文件。
