# kane-task-cleanup · 任务清理

任务或会话结束后，由你显式调用 `$kane-task-cleanup`。直接说「只保留成果」或「清临时文件」，Agent 核实归属、用途和占用后，永久删除符合条件的临时文件或废弃产物，无需重复确认。创建文件时无需预先分类或登记。

## 选择清理范围和程度

- **范围**可选本次任务（默认）、当前会话、指定 Goal 或项目。范围有歧义时才询问。
- **程度**可选清临时文件、只保留成果、按编号处理或只看清单。「只保留成果」也包括可重建的一次性环境和已被替代的旧产物。只调用技能而未指定程度时，Agent 会先展示候选供选择。

敏感副本、Git 已跟踪的过程文件、归并或脱敏需要授权具体对象及动作。要停止后台任务时，另行确认实例和停止方式。文件和后台任务都有待确认项时，一次问清。

## 用法

```text
使用 $kane-task-cleanup，只保留这次任务的成果。
```

```text
使用 $kane-task-cleanup，清理这个 Goal 的过程文件，只保留最终报告和交付所需的文件。
```

```text
使用 $kane-task-cleanup，只停掉刚才为烟测启动的服务。
```

也可以说「先盘点」，只查看候选清单。跨任务清理需要能定位到对应的记录或产物路径。正式测试、仍在使用的文件和归属不明的对象会保留。清理对象限本地任务文件与本次启动的后台实例。

## 依赖和输出

复制整个技能目录即可使用。盘点需要运行时能读取相关任务记录。执行清理时需有删除文件的权限，停止后台任务时需能查询和停止指定实例。

结果直接在对话中汇报，包含已删除项、保留项和跳过或失败的原因。只有明确要求使用废纸篓时才移动文件，结果单列。若停止了后台任务，同时汇报实例的核验结果。
