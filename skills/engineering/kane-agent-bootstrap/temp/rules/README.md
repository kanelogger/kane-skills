# Project Rules

根目录 `AGENTS.md` 保留沟通原则、高频红线和导航。详细规则按任务加载，避免把无关上下文全部塞给 Agent。

- [workflow.md](workflow.md)：上下文阅读、关键歧义、计划与验收、范围控制、自主推进、审阅与收尾。
- [testing.md](testing.md)：针对性回归测试、完整 E2E、回归范围与项目全量触发条件、验证报告要求。
- [security.md](security.md)：权限、敏感数据和外部系统边界。
- [git.md](git.md)：工作区保护、提交与推送的授权边界及仓库内执行流程。
- [code-style.md](code-style.md)：确定性机制、手写代码的取舍、导入与控制流约定、工具边界。

规则冲突时保留证据，选择权威性更高且更新更近的来源，禁止自行拼接出第三套规则。
