# 安全规则

- 只加载当前任务所需的文件、知识与工具。
- 密钥、认证 token、本机密码、生产数据和未脱敏私有材料不得进入 Prompt、日志、提交物或交接产物；只引用变量名和占位值。
- `.env*`、本机 Agent 状态、依赖与测试产物不入库；发现敏感文件可提交时先报告，不回显取值。
- 外部系统写入、生产操作、发布和不可逆动作须获得人工批准。仓库声明不授予外部权限。
- 本地可逆修改按当前任务授权执行，保留用户已有改动与忽略的本机数据。
- 技能恢复只读访问清单固定的 GitHub 来源，在本机创建缺失技能目录；不执行上游代码、不覆盖冲突内容。
- 权限范围与任务不匹配时停止依赖该权限的步骤，记录阻塞；继续可独立完成的授权工作。
