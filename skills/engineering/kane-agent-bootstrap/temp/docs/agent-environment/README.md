# Agent 环境索引

本目录提供采用模板时需要填写和核对的环境约定。当前模板提供协作规范、填写模板与最小忽略配置，没有环境诊断、技能恢复或状态管理脚本，没有应用服务、CI 或部署目标，也尚未完成真实开发演练。

Agent 开始或恢复任务时默认读取根 [project.yml](../../project.yml)。[project.template.yml](../project.template.yml) 提供通用填写格式，采用时复制到目标项目根目录；当前随附清单声明本目录没有运行入口和应用服务，按实际项目更新。

| 需要确认的内容 | 入口 |
| --- | --- |
| 工具链、实际命令、前置条件、副作用及本地与 CI 差异 | [命令登记](commands.md) |
| 当前工具、文件、网络和服务是否可用，证据能证明什么 | [能力核对](capabilities.md) |
| 工作区、权限、资源归属及可选共享状态协议 | [网络、工作区与本地状态](network-filesystem.md) |
| 技能来源、版本、完整性、冲突与恢复 | [技能管理](skills.md) |
| 干净副本中的真实任务、中断恢复和独立审阅 | [开发演练](development-rehearsal.md) |
| 目标、进度、验证与跨会话交接 | [任务规范](../../tasks/README.md)、[任务模板](../../tasks/TEMPLATE.md) |

## 在采用项目中填写

1. 从实际配置和实现中确认工具链、服务与命令，统一填写 `project.yml`。版本、命令定义和复杂操作引用所属配置或已有说明，不在本目录再维护第二份清单。
2. 明确工作区和临时资源归属；按任务核对文件、网络及外部系统的当前权限。凭据与本机配置不写入共享文档。
3. 只登记实际需要的技能和外部工具，保留来源、版本与恢复边界。没有使用技能的任务不必建立技能清单。
4. 在任务记录中保留本次环境、输入、验证结果和未覆盖项；完成记录按[任务规范](../../tasks/README.md)的归档约定保存，有价值的经验回写根[经验库](../../LESSONS.md)。

本地与 CI 共享检查入口时，仍需分别记录实际运行结果。配置可读、环境探测成功、测试通过及远端发布成功是不同结论，不能相互替代。
