# 项目环境与命令填写指南

项目环境统一在根 [project.yml](../../project.yml) 声明，格式见 [配置模板](../project.template.yml)。当前清单声明本目录没有固定工具链、应用服务或安装、测试、构建、发布入口。本文件解释填写与核对方法，不再维护另一份环境或命令表。

## 填写与读取

- 采用时根据实际文件填写 `project.yml`，替换全部占位值；保留已有有效配置，不从其他项目照搬版本、命令或退出码。
- `[]` 或 `{}` 表示已确认没有相应项目要求；`null` 或省略表示尚未声明，不能据此推断能力不需要或已经具备。模板示例不可执行。
- 路径相对清单所在的项目根目录，命令另声明其工作目录。凭据只引用变量名和配置来源，不填写秘密值、私有地址或本机绝对路径。
- 清单提供执行环境上下文，不自动安装工具、执行命令或授予权限。读取后按[能力核对](capabilities.md)检查本次需要的能力，结果写入实际任务记录。

## 字段分工

| 清单字段 | 填写内容与权威来源 |
| --- | --- |
| `project` | 项目标识、用途、协作语言和记录时区；协作入口引用它，不重复维护这些值 |
| `environment.supported_platforms` | 已声明的操作系统、架构范围；不是本机探测结果，未知时保留 `null` |
| `environment.toolchains` | 名称、版本要求的权威来源及核对方法；版本优先引用依赖清单、锁文件、工具配置或镜像 |
| `environment.commands` | 实际命令或手工步骤、工作目录、定义来源、前置条件、副作用、验证范围和失败处理 |
| `environment.services` | 所需服务、连接配置来源、就绪与启动/停止方式；复用已登记的命令键 |
| `environment.tools` | 项目、宿主或用户提供的技能与工具；记录来源、可得版本来源及触发用途，细节引用所属管理器 |
| `environment.variables` | 所需变量名称、用途及配置来源，不保存秘密值 |
| `environment.local_paths` | 本地状态、缓存或证据位置及保留要求；临时路径与持久证据分清 |
| `requirements` | 按任务需要的文件、网络等能力范围；实际权限仍以当前用户授权和执行环境为准 |

命令副作用包括文件写入、安装、缓存、端口与外部系统变更。失败处理应说明实际判定、取消、有界等待及部分完成时的恢复；复杂流程引用已有操作文档。诊断涉及联网、安装、启动服务或写入时，不能称为只读探测。

## 运行与 CI 边界

运行前核对清单引用的定义和当前工作区；与实际配置不一致时说明差异并修正声明，不能依据陈旧命令直接操作。实际命令、输入、环境、结果和报告位置按[任务规范](../../tasks/README.md)保存在对应记录中。

当前模板没有 CI。采用项目建立 CI 后，清单引用实际配置和检查入口，复杂的触发条件、环境差异及产物保留方式可在所属说明维护。本地通过、远端 CI 成功和发布成功分别由对应版本的实际证据支持，配置相同不能证明运行相同。
