# 技术决策记录

ADR 保存需要长期解释的方案选择、理由、替代方案与适用边界。当前尚无已登记的项目技术决策；[TEMPLATE.md](TEMPLATE.md) 是写作模板。

出现重要兼容、维护、部署或架构取舍时再建立记录，普通任务无需补写 ADR。建议每项使用 `NNNN-短名.md`，按目标项目需要调整编号方式。

- 写清日期、状态、背景、选择、理由、代价与重新评估条件，区分提议、已接受和被替代。
- 接受决策不证明方案已实现或运行通过；当前行为以 [实现文档](../subsystems/README.md)、实际源码及配置为准。
- 进度和验收保存在 [任务记录](../../tasks/README.md)，已结束任务按约定归档；ADR 引用必要证据，不代替完整验收历史。
- 有证据的失败案例进入 [LESSONS.md](../../LESSONS.md)，稳定工程约束回到所属规范。被替代决策保留历史并链接后继决策。
