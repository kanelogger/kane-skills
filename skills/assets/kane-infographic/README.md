# kane-infographic

把文章、笔记、主题材料或数据做成独立信息图，交付提示词、图片或两者。先补齐制作要求，再将答案落实到文案、布局与视觉表现。

每张成图（含系列每张）及每条独立完整提示词默认带精确小写拉丁文字水印 `kanelogger`，不随图内语言翻译。默认右下角、小号清晰，`opacity 0.6`（60% 不透明），与画面协调，留足安全边距，不遮挡主体或正文，不影响整体。普通“无字／纯图”模式仍保留该水印；明确要求无水印或修改文字、位置、不透明度等时遵从，不额外询问确认。

## 使用

提供材料，可附参考图；只有主题时会先明确范围与依据。在 Codex 中输入 `$kane-infographic`，其他支持技能的 Agent 可按名称调用。

```text
使用 $kane-infographic，只写一张信息图提示词：给非技术同事看，发手机群，米白深绿剪纸风，3:4，不要求固定像素，图内中文。材料如下……
使用 $kane-infographic，图片和提示词都要：面向产品经理，用于内部报告，扁平几何风，1536×1024，共两张，图内中文；其余小细节你定。材料如下……
使用 $kane-infographic，先做方案，给出信息取舍和推荐规格，等我确认再制作。材料如下……
```

## 关键提问

会集中补齐内容目标、交付形式、受众与用途、风格、尺寸、语言、数量及必要限制。仅提示词也要问清；只有比例要求时无需强填像素。适用于本次图的已有答案不重问，“风格你定”等委托只作用于对应项，一般委托不代替尚未选择的交付形式。

只回答部分问题时会补问剩余关键缺项，漏答或沉默不算接受推荐。回答或明确委托前不定稿、不试生成；先做方案可以保留待定项。

最终答案直接进入完整提示词，改变文案、布局和具体视觉特征；每条提示词都独立写全实际水印要求。结论保留主体范围与判断时点，现状与未来观察分开表达。完整提示词实际用于出图，工具支持水印不透明度设置时实际采用默认值 0.6 或你明确修改的值，再对照最新要求逐张核查，包括水印文字、位置、不透明度设置、清晰度、安全边距与遮挡情况；手机任务按预计展示宽度实际查看，正文、状态和限定注记都要无需放大可读，未检查项如实标明。

## 交付

- **先做方案**：采用要求、信息取舍、布局建议和待定项。
- **仅提示词**：每张可独立使用的完整提示词，不生图。
- **仅图片**：实际图片与验收状态，提示词用于内部生成，不强制另交文件。
- **两者都要**：完整提示词、实际图片与验收状态。

完整提示词兼作制作规格，无需另交需求表或分析文件。需文件时默认保存在工作目录的 `infographics/<主题短名>/`，指定位置优先，按需保存 `plan.md`、`prompts/` 或真实 `images/`。旧产物使用新目录或版本名保留；续做只修改指定项。也可直接交付工具原生结果。

## 依赖与限制

技能自包含，无脚本或固定后端。仅提示词不需要生图服务；图片需要可用且已授权的生成与看图工具，不自动安装服务或扫描密钥。

工具能力不足时说明差异并确认调整；没有工具则明确图片未生成，完整请求仍未完成。“矢量风”不保证可编辑 SVG，印刷要求也需核查真实文件属性。

默认每张初次生成后最多再尝试一次，用户预算优先；无法看图则标记未验收，有错误的候选不会标为合格终稿。不附带发布。
