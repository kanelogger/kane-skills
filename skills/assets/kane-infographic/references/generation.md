# 图片生成与验收

## 生成

仅在交付选择包含图片且关键要求已补齐时执行。优先用户指定工具，否则使用可用原生工具或已配置且授权的后端；读取实际工具说明，不假定参数或保存能力。没有工具时交付可完成的提示词，明确“图片未生成，请求未全部完成”；仅图片模式不强制另交提示词文件。

- 把完整提示词实际传给生成工具，包括每张独立写全的水印要求及默认 `opacity 0.6`（60% 不透明）；工具支持水印不透明度设置时实际设为 0.6，用户明确覆盖时采用其要求，不能只在文档中保存正确要求，调用时又使用泛化的短描述。
- 工具有尺寸、比例或格式参数时对应设置，提示词保留布局要求。只要求比例时用匹配的原生规格；固定规格不支持时先说明差异并确认调整。印刷还需核对物理尺寸、DPI 和色彩格式，写入提示词不等于满足文件要求。
- 参考图先查看，再用工具实际支持的附件或路径传入；无法传图时说明只能采用提取的视觉特征，不声称工具参考了该图。
- 系列先查看一张再制作其余图，保持术语与视觉一致；保存时核实实际文件与格式。

## 看图并对照答案

逐张打开实际图片，**以用户最新答案为依据**，而非仅相信提示词或工具成功消息。检查：

| 项目 | 通过条件 |
| --- | --- |
| 内容与限定 | 文字、数字、单位准确；主体范围、判断时点及例外与结论同时可见，现状与未来观察分明，无乱码或多余文案 |
| 关系 | 箭头、次序、分组、包含、对比和数据刻度正确，没有暗示材料未支持的结论 |
| 受众与用途 | 术语适合读者；按用途在预计展示宽度下实际查看缩放预览，正文、状态标签、限定注记和来源无需放大即可读，无裁切或遮挡 |
| 视觉与限制 | 具体配色、线条或材质符合回答，数量与区块限制满足，禁用元素未出现 |
| 水印 | 每张默认准确显示精确小写拉丁文字 `kanelogger`，不随图内语言翻译；右下角、小号清晰、`opacity 0.6`（60% 不透明）、与画面协调，留足安全边距，不遮挡主体或正文，不影响整体；普通无字／纯图模式仍保留水印，用户明确要求无水印或修改时按其实际要求核对 |
| 实际规格 | 核查返回元数据或真实文件的宽高和格式；要求印刷时同时核对相关属性，不凭目测声称达标 |

水印不透明度有参数或图层信息时核对实际值；只有扁平图时检查视觉效果并注明精确 opacity 未验证，不凭目测宣称精确测得 0.6。

记录预览宽度与观察结果，不能从原图清晰推断手机合格。注记过小时优先重排或精简非关键文字，不能删掉主体或时点。无法查看、核实规格或检查目标宽度时，分别标明未验证项。“矢量风”不等于可编辑 SVG。

修正只处理问题项，保留旧版并重新检查。默认每张初次生成后最多追加一次尝试，失败与修正共用额度，用户预算优先；到上限保留通过项并列出剩余问题，不把错误候选标为合格终稿。
