# kane-xhs-images

把文章、笔记或主题材料做成图形主导、浅显易懂的小红书单图或系列分享图。先问清需求，再把答案落实到每张图的文案、图形关系和视觉表现。

## 使用

在 Codex 中输入 `$kane-xhs-images`，并提供材料、文件或主题。可附照片、参考图和品牌要求。

```text
使用 $kane-xhs-images，把这段经验做成小红书分享图，先问我制作要求。材料如下……

使用 $kane-xhs-images，只给 3 张完整提示词。面向刚工作的年轻人，让他们学会挑出今天最重要的事。竖向 3:4，不固定像素，简体中文、少字图解，米白底手写彩绘涂鸦简笔风。不加成功学标语，无参考素材，其他细节你定。材料：先列出任务，再选出今天最重要的一件，做完后回看。

使用 $kane-xhs-images，图片和提示词都要。给第一次养绿植的人，用摄影拼贴讲清浇水前的检查步骤。先看方案，等我确认。材料和参考照片如下……
```

## 会问哪些问题

| 制作选择 | 如何影响结果 |
| --- | --- |
| 仅提示词、仅图片、两者或先看方案 | 决定是否生图及实际交付内容 |
| 受众与看完的收获 | 改变用词、例子、重点和解释深浅 |
| 风格 | 变成具体配色、线条、材质、照片或绘画表现；不只贴风格标签 |
| 比例与尺寸 | 推荐竖向 **3:4**，接受后才采用；也可自定，只定比例不必强填像素 |
| 张数与组织 | 做单图总览或系列展开，不固定套封面和结尾 |
| 文字语言、详略与必留原句 | 决定逐字文案、层级和信息密度 |
| 参考素材、必留与禁用元素 | 决定怎样用参考，以及实际画面中的保留与排除 |

会集中补齐本次缺项，已给的答案不重问。仅提示词也需要这些设计信息；推荐、漏答或沉默不算同意。可以明确委托某一项或其余制作要求，但交付形式要明确选择。只答部分时继续补问，关键项未齐前不定稿、不试生图。信息齐全即可制作，不强加多轮确认；你要求先确认方案时会等待。

风格开放选择，包括手写彩绘涂鸦简笔、摄影拼贴、简洁编辑式或你描述的形式。参考图可用于借风格或保留真实主体，会先问清用途；需要真实照片时不会把生成的摄影风图当作实拍。

## 怎样更图形化

每张先确定一个主要理解目标，再用动作场景、步骤、对照、分组、分支或生活比喻表达。主图承担解释，短标题和标签点明关系，避免长段文字塞进卡片再配装饰图标。系列每页都有新增内容，不用固定结尾或互动口号凑页。

你的回答会直接进入完整提示词。例如面向新手会改成日常例子，3:4 会改成纵向阅读，摄影拼贴会使用照片主体和剪贴层次；不会继续使用此前推荐的手绘或横向布局。若必留文字与固定张数、可读性冲突，会让你选择可调整项。

## 交付与保存

每张分享图（含系列每一张）和独立完整提示词默认带文字水印 `kanelogger`：精确小写、不随图内语言翻译，放在右下角，小号清晰、与画面协调，留安全边距且不遮挡主体或正文。无字、纯图或仅标题也保留水印，无需额外确认；你可以明确要求无水印，或修改文字、位置。生成后逐张检查水印，漏印或错字会列为待改。

- **先看方案**：采用要求、逐页要讲什么与怎么画、建议及待定项。
- **仅提示词**：每张可独立复制的完整提示词，不生图。
- **仅图片**：实际图片及验收状态，不强制另交提示词文件。
- **两者都要**：完整提示词、实际图片及验收状态。

需要文件时默认保存在工作目录的 `xhs-images/<主题短名>/`，指定位置优先，按需保存 `plan.md`、`prompts/` 或真实 `images/`。也可直接交付工具原生结果；原材料和旧版本保留，不创建占位图片。

## 依赖与限制

技能自包含，无脚本或固定后端。提示词无需生图服务；图片需要当前可用且已授权的生成、看图工具。不会自动安装服务、扫描密钥或附带发布。

图片使用完整提示词生成，并逐张检查图文关系、文字、风格、真实规格和手机宽度预览。不能查看或核实的项目会标明未验证。默认每张初次生成后最多再尝试一次，失败与修正共用额度，用户预算优先。

没有可用工具会明确图片未生成、完整请求未完成；所需比例或固定规格不支持时先说明差异并询问调整。不保证流量或互动效果。
