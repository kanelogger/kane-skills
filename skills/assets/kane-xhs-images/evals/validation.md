## 创建阶段的独立上下文试用

以下为创建阶段的历史观察，早于本轮水印修订，不作为 opacity 已验证的证据。各场景由全新上下文 Agent 仅读取技能和适用参考执行，不读取预期断言；提问场景使用离线文本回复，不向真实用户发测试问题。不调用图片工具。已审阅实际回复和完整提示词。

| 场景 | 观察结果 |
| --- | --- |
| 1：缺失制作要求 | 集中询问七组关键缺项，3:4 作为待接受的推荐，风格包含手绘与摄影拼贴；未定稿或生图 |
| 2：只答交付和风格 | 沿用仅提示词与摄影拼贴，只补问受众、画布、数量、文字和素材限制；未把“继续”当作接受其余建议 |
| 3：最新答案改变摄影拼贴 | 恰好两份独立提示词，采用中年家长的家务场景、1:1、米白暗红、中文、生成摄影素材和无人无箭头要求；用物件分组、放大、完成状态解释三步，不沿用旧的三张手绘建议 |
| 4：手写彩绘涂鸦图解 | 恰好三份独立提示词，采用年轻职场人的任务、3:4 纵向、彩铅蓝绿橙色、短中文标签；以物件对应、圈选和未完成空框表达步骤，没有额外封面或结尾 |
| 5：容量冲突 | 指出约 2400 字与单张 600×800、少字图解的冲突，索取材料并请用户决定可放宽项；未自行改字、增页或定稿 |
| 6：工具无法满足规格 | 首次回复正确停下但未提出选择问题；补强参考中的选择要求后，以全新上下文复测，明确请用户选保持 1200×1600 等待工具，或改成 1024×1024；未生图、未覆盖旧图 |
| 7：方案与真实照片 | 给出三页具体图形方案，将真实活动照片列为待补素材，按用户要求等确认，不用合成图冒充实拍 |
| 8：无法查看不算通过 | 明确实际图、规格、手机可读性均未验证，不凭他人描述确认验收 |
| 9：只定比例但工具不支持 | 识别 1024×1536 为 2:3，明确请用户选保持 3:4 等待工具或改为 2:3；未要求补固定像素，未生成 |

提示词试用保留“不保证所有事都能做完”的内容边界，受众、风格、比例、张数和禁用项进入每张实际提示词；没有仅交一份正确需求摘要。

独立只读审查未发现阻断问题；按审查建议补齐了“只定比例、后端却无匹配规格”的分支，并执行场景 9 复核。
