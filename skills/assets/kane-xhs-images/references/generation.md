# 图片生成与验收

仅在用户明确选择图片且关键制作要求已齐时读取和执行。本文件不要求额外例行批准。

## 生成

1. 优先用户指定工具，否则选择当前可用的原生工具或已配置且授权的后端。先读真实工具说明，不假定模型、参数、参考图支持或保存能力。没有可用工具时交付能完成的部分，明确“图片未生成，完整请求未完成”，不以提示词替代图片报完成。
2. 将每张**完整提示词**实际传给工具，逐张包含默认水印 `kanelogger`、`opacity 0.6`（60% 不透明）或用户明确修改、取消的要求；工具支持水印不透明度设置时实际设为 0.6，用户明确覆盖时采用其要求；有比例、尺寸等参数时同步设置。只定比例时选匹配的原生规格，不额外强求像素；所需比例或固定尺寸不支持时，说明差异并请用户选择：保持规格等待合适工具，还是明确修改规格？答案到达前不生成，不能只报告“需要另一工具”后结束。不能只在提示词里写正确尺寸就算满足，也不能为凑比例擅自拉伸或裁掉内容。
3. 参考图先查看，再通过工具支持的附件或真实路径传入，明确借风格或保留主体。无法传图时说明只能转述视觉特征；合成的摄影风图片不称为用户实拍。
4. 系列先生成并查看一张，检查图形表达与系列样式后再做其余；无需逐页等待用户批准，除非用户要求。支持参考图时，可把合格首图作为后续的视觉参考，但每页仍传入完整提示词。实际文件保存前核实格式，不伪装扩展名。

默认每张初次生成后最多追加一次尝试，失败重试与修正共用额度，用户预算优先。保留旧候选，只处理问题项；额度用尽就保留通过项，列出未完成或仍不合格项。

## 逐张查看实际图片

不能只相信工具成功消息或提示词。打开实际图片，并按用户最新答案检查：

| 项目 | 要看什么 |
| --- | --- |
| 文字与事实 | 有无错字、乱码、漏字、额外口号；数字、单位、条件、范围、时点与来源属性是否准确且可见 |
| 水印 | 系列每张默认有精确小写文字 `kanelogger`，右下角、小号清晰、`opacity 0.6`（60% 不透明）、与画面协调、有安全边距、不遮挡主体或正文且不影响整体；不随图内语言翻译；用户明确修改或取消时按其要求核对 |
| 图形是否解释内容 | 主体、位置、动作、顺序、对比、分组和箭头有无误导；图与标签是否一一对应；是否退化为长段文字加装饰 |
| 受众是否看得懂 | 用词和场景是否适合读者，必要术语是否有具体解释，关键条件是否被藏进小字 |
| 风格与系列 | 用户指定的配色、材质、手绘或照片表现是否出现；禁用项是否缺席；各页主体、色彩、字形与顺序是否一致 |
| 真实规格 | 用返回元数据或真实文件核对宽高、比例、格式及张数，不凭目测；未能核实就标记未验证 |

水印不透明度有参数或图层信息时核对实际值；只有扁平图时检查视觉效果并注明精确 opacity 未验证，不凭目测宣称精确测得 0.6。

按预计手机展示宽度实际查看缩放预览；未知时可用约 360 像素宽初检，并记录所用宽度。标题、短标签和必要限定应无需放大可读，主图含义能迅速辨认，无裁切或遮挡。原图清晰不能证明手机预览合格；未做预览就明确“手机可读性未验证”。字太小先重排、改短非关键文字，容量冲突回到用户选择，不能删掉关键条件。

修正时更新完整提示词，再重新查看实际结果与规格。水印缺失、拼写错误、被裁切或遮挡内容同样列为待改，遵守前述尝试上限。存在事实、乱码、水印或规格问题的候选不能标为通过；无法看图时标为“已生成、未验收”。交付可访问的真实图片或工具原生结果，并简短说明已验证与未验证项。
