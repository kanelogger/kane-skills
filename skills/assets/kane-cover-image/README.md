# kane-cover-image

围绕主要传播主题设计封面。可以从文章、摘要、标题或主题开始，先集中补齐影响结果的要求，再将回答落实为构图、主体、风格、文字和尺寸等具体视觉指令。

## 使用

在支持技能的 Agent 中按名称调用；Codex 中可输入 `$kane-cover-image`。

```text
给这篇文章做封面，先集中问清缺少的制作要求。
只写 1 张封面提示词：面向开发新手，用于技术博客，温暖手绘风，横向 3:2，无字；主体要有一座纸桥，没有其他元素限制。
图片和提示词都要，1 张：面向产品经理，用于公众号头图，简洁几何画风，1536×1024，正文文案仅写中文“重新理解协作”；配色请给出具体推荐让我选。
先做封面方案，列出视觉主题、构图和风格建议，等我确认后再继续。
沿用已确认要求，只重做第 1 张，保留旧版本。
```

## 输入与要求

提供可读文件、粘贴文字或说明主题，可附参考图片。不要求完整文章；只有标题或主题时，会围绕已知信息设计，需要时补问核心观点。参考图用于明确你希望采用的视觉特征。

| 要求 | 对结果的影响 |
| --- | --- |
| 交付形式：仅提示词，或图片和提示词都要 | 决定是否调用生图工具；仅方案请求停在方案阶段 |
| 受众与用途 | 决定视觉重点、信息密度及缩略图可读性 |
| 风格：画风、情绪、配色或参考 | 决定主体表现、线条、材质、色彩及氛围 |
| 尺寸：比例、精确像素与裁切要求 | 决定布局、画幅与主体和文字的安全区域 |
| 可见文字：无正文文案，或确切文案与语言 | 决定正文写什么及如何排版；默认水印另行保留 |
| 数量、必须与禁止元素 | 决定交付张数、方案差异及画面边界；可明确无额外元素限制 |

只询问当前适用的缺项，尽量集中一轮，已有答案不重复问。数量未说时会询问并推荐 1 张。风格已明确时，未限定的配色和细节会按该风格设计，无需填写每项美术参数。你可以针对具体事项授权推荐，例如“配色由你推荐”；不会把所有关键项藏在一个总推荐选项里，也不会将沉默视为接受。

交付形式需要明确选择“仅提示词”或“图片和提示词都要”，同义说明同样有效；“做封面”“直接做”或一般设计委托不代替这项选择。仅提示词也需要明确影响提示词的关键要求，“快速做”“直接生成”等说法不会跳过尚未回答的关键问题。仅方案时可以先呈现建议和待确认项，到此停止；收到制作要求后，才完成用于交付的提示词或实际生图。

每项回答都会成为具体绘制要求和验收要点，不只留在需求表里。多张分别落实各自要求，只共享你要求共用的规范。涉及阶段或趋势时，还会保留材料说的是谁、截至何时、哪些仍待验证，不把个别公司的进展画成整个行业的结论；材料不清且影响画面时才补问。技能不设固定风格库。

需要灵感时，可参考[精选视觉方向](references/styles.md)：**深色触感编辑**以深色留白、近景材质与克制排版表现器物和生活方式；**东方水墨木刻**以手工线描、透明淡彩与明亮纸面表现文化、自然和文学主题；**静物手写独白**让短句像热气一样从日常物件升起，适合生活随笔与个人感受。三者均按主题选用，文案与构图随本次要求调整，也可采用其他风格。

每张封面和独立完整提示词默认带文字水印 `kanelogger`：精确小写、不随图内语言翻译，放在右下角，小号清晰，opacity `0.6`（60% 不透明），与画面协调、不影响整体，留安全边距且不遮挡主体或正文。无字、纯图或仅标题也保留水印，无需额外确认；你可以明确要求无水印，或修改文字、位置、不透明度等设置。工具支持水印不透明度设置时实际采用 `0.6`，你明确修改时采用你的值。生成后逐张检查水印，漏印或错字会列为待改。

## 交付

| 形式 | 产物 |
| --- | --- |
| 仅方案 | 需求摘要、主要传播主题、视觉设计建议及待确认项，到此停止 |
| 仅提示词 | 设计简报和可独立使用的完整提示词，不调用生图工具 |
| 图片和提示词都要 | 设计简报、完整提示词、真实图片或工具原生结果，以及逐张查看的验收结论 |

默认输出到输入材料同级 `covers/<主题短名>/`；无文件输入时使用工作目录下 `covers/<主题短名>/`。按交付范围保存 `brief.md`、`prompts/01-cover.md` 等文件。工具提供真实本地图片时保存到 `images/01-cover.<ext>`；仅提供原生结果时直接交付该结果，不编造本地路径或创建图片占位文件。不复制原稿，续做保留旧版本。

## 依赖与限制

技能可单独复制使用，无自带脚本。实际出图依赖运行时可用的图像生成或编辑工具及其授权；优先尊重指定工具，不自动安装后端或扫描密钥。尺寸、格式、参考图与文字能力以工具为准；无法满足要求时会说明差距，并等你确认调整。

生成后查看原图与手机缩略图，核对答案、主体范围、判断时点、文字和真实规格。手机小图会分别记录“能辨认什么”和“能读出什么关系”，标明仍需标题支持的含义；没有指定展示宽度时可用约 360px 宽作初检，不冒充平台实测或读者测试。待改、未验证及无法看图的状态如实说明；无生图工具时交付可完成部分并标记图片未生成。

默认每张初次生成后最多追加 1 次尝试，失败重试与验收修正共用这次额度；你的预算或次数限制优先。达到限制后停止并说明剩余问题。所有实际图片都附完整提示词。
