## 关键行为验证

| 场景 | 已观察到的结果 |
| --- | --- |
| 缺项、局部委托与仅提示词 | 集中补问适用缺项，不重复已答，不把委托风格扩大到其他要求，不在待答时定稿或出图 |
| 新答案、精确文字、遮挡与多候选 | 最新答案替换旧推荐，确切标题及标点、底部遮挡、逐张风格尺寸和禁用项进入独立提示词 |
| 主体范围与判断时点 | 已知材料直接提取；强制阶段图但范围时点缺失时只补问必要项，不把个别进展泛化为行业结论或将未来窗口当成既定结果 |
| 手机可读性 | 实际查看 360px 预览，分别记录物体识别、关系理解与标题依赖，不以物体可数清代替完整语义通过 |
| 候选不符、原图缺失或无工具 | 区分各项通过与失败，标明待改和未验证；不把用户记录的原图规格当作实查，不以旧图或提示词冒充新图 |
