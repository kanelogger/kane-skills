# 图片生成与验收

仅在用户已选图片交付、适用关键要求已有答案后使用。

## 选择工具并传入要求

用户指定工具时核实其可用性和所需能力；未指定时优先当前运行时原生生成或编辑工具，其次为用户已配置且授权的后端。读取实际工具说明，不假定模型名、参数、原生比例、附件方式或本地保存能力，也不维护跨运行时包装脚本。

- 先准备完整最终提示词，将默认水印 `kanelogger` 或用户明确修改、取消的要求逐张写入并实际传给工具；有文件交付时先保存，再把同一份内容及对应规格交给工具。参考图先查看，以工具支持的真实附件、会话图片或文件传入，不能只在提示词中写一个工具无法读取的路径。
- 把尺寸、格式落实到参数及提示词，真实规格以输出核实。工具不支持既定要求时，说明差异和替代，等用户决定；裁剪缩放的影响同样说明，不静默裁掉主体或文字。
- 无工具时交付可完成的设计与提示词，明确“图片未生成，请求尚未全部完成”，不以旧图代替。
- 生成多张时先查看一张，再按各张已确定要求继续；仅沿用用户要求共用的视觉规范，不强求不同方向的候选统一风格、尺寸或文字。每张仍保留独立提示词与验收结论，不擅自增加候选数量。

## 对照答案查看真实结果

查看实际图片，以文件信息或可靠元数据核实规格，逐项对照摘要中的“答案 → 绘制要求 → 验收要点”，不凭调用成功或提示词正确推定成图通过。

| 检查项 | 需要查看的结果 |
| --- | --- |
| 主题与主体 | 必需元素出现；可见关系不扩大行业、公司或样本范围，不把阶段信号、当前判断和未来结果混为一谈 |
| 受众与用途 | 单独看目标大小的缩略图，记录可辨认的主体、可读出的关键关系及仍需标题或解释的部分；必要时模拟已知裁切 |
| 风格与参考 | 实图的配色、线条、质感、光影及借鉴范围符合答案，禁用元素没有混入 |
| 可见文字 | 逐字核对标题、其他文案及语言，无乱码或多余文字；无字模式除采用的水印外没有文字或伪文字 |
| 水印 | 每张默认有精确小写文字 `kanelogger`，右下角、小号清晰、与画面协调、有安全边距且不遮挡主体或正文；不随图内语言翻译；用户明确修改或取消时按其要求核对 |
| 尺寸与布局 | 真实比例、固定像素和格式满足要求；主体与文字未越出已确定的安全区域 |
| 数量与一致性 | 张数对应请求，系列中的指定主体和视觉规范保持一致 |

手机展示未给尺寸时，可用约 360px 宽等比预览初检并记录实际宽度，这不是平台实测。先描述小图能读出什么，再对照文章与用户答案；“四个物体可数清”不能替代“关键关系可理解”。语义错读会改变判断时标为待改，优先简化关系或更换隐喻，不靠擅加文字补救，也不把完整含义只藏在提示词里。

受众适配和情绪是设计判断，记录依据，不宣称已验证真实读者理解或传播效果。未知规格、裁切或未做的检查标为未验证；需依赖平台规范时查证，不编造。无法看图则标记“已生成未验收”，不把待改候选列为合格。

## 修正与停止

需要修正时，保留原版本，只改变不符要求的部分；使用支持的编辑工具或完整修正提示词重新生成。水印缺失、拼写错误、被裁切或遮挡内容同样列为待改，遵守下述尝试上限。文字错误不能靠擅改文案、改语言或去掉标题来规避，尺寸不符也不能倒改需求记录。

默认每张初次生成后最多追加一次尝试，失败重试和质量修正共用这一次额度；用户的次数或预算要求优先。达到上限仍有问题则停止该图，交付已有结果、完整修正提示词与未解决项，不自行无限重试或切换收费服务。

有文件交付时另存版本，并更新摘要中实际采用的图片和对应提示词。最终报告说明哪些图已验收、哪些尚未生成或存在问题，并给出真实文件链接或工具原生结果。
