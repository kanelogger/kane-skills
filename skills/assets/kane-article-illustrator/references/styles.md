# 视觉风格

图形类型负责表达关系，画风负责视觉感受，两者分开选择。用户风格和参考图优先；推荐必须适合已确定的受众与用途，不把下表当作封闭选项。

| 风格 | 可执行的视觉特征 |
| --- | --- |
| 手绘讲解 | 米白底、轻微不规则深色线条、少量柔和色块、短标签；清晰优先，不强制手写字 |
| 扁平矢量感 | 几何形状、统一描边、有限配色、清楚的连接与分区；描述画风，不承诺 SVG 文件 |
| 编辑插画 | 一个概念或隐喻、鲜明主体、克制色彩和留白，适合观点与评论 |
| 技术蓝图 | 精确节点、统一线宽、明确方向和图例；网格或纹理不能遮蔽关系 |
| 水彩叙事 | 柔和边缘、自然色彩、具体场景与情绪焦点，适合随笔和故事 |

先查看参考图，明确借鉴主体、构图、风格还是配色，不带入与文章无关的文字或事实。将选定风格写成可复用规范：背景、主要颜色、线条、质感、主体特征和留白。图内正文语言与用户要求一致；默认水印仍为精确小写拉丁文字 `kanelogger`，不随语言或风格翻译。

同篇固定这些规范，相同概念沿用相同符号和颜色；颜色之外用标签、形状或线型区分关系。重复主体记录稳定特征，工具支持时传入已通过的基准图。

构图按尺寸和展示场景调整：横向适合流程与并列对比，方形适合聚焦概念，纵向适合分层或时间线。小屏展示减少节点和文字，不靠缩小字号塞进内容；精准读数或复杂关系优先清晰结构，避免纹理和隐喻干扰。
