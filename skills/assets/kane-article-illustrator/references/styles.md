# 视觉风格

选择风格前先确定图形类型和图的作用。风格改变线条、质感和氛围，不改变文章中的事实关系。用户提供的风格或参考图优先，不把下表当作封闭选项。

## 首版风格

| 风格 | 适用内容 | 可执行的视觉描述 |
| --- | --- | --- |
| 手绘讲解 | 概念、教程、知识分享 | 米白底、深色轻微不规则线条、少量柔和色块、短标签和简洁图标；优先清晰，不强制手写字 |
| 扁平矢量感 | 产品、流程、对比、通用技术 | 几何形状、统一描边、有限配色、清楚的连接线和分区；“矢量感”描述画风，不承诺 SVG 文件 |
| 编辑插画 | 观点、评论、杂志文章 | 一个明确的概念或隐喻、鲜明主体、克制的色彩与有意识的留白，避免拼成文字海报 |
| 技术蓝图 | 架构、组件、系统关系 | 精确节点、统一线宽、明确方向和图例、少量网格或蓝图质感，装饰不能遮蔽关系 |
| 水彩叙事 | 随笔、生活、回忆、情感场景 | 柔和边缘和自然色彩、具体场景与情绪焦点；不用于需要精确读数的图表 |

没有偏好时，依据文章推荐一套并写清理由：知识讲解可用手绘或扁平，复杂结构优先清晰节点和连接，观点或故事优先概念与场景。不要把手绘、16:9、卡通人物或满幅信息图设成所有文章的固定答案。

## 参考图与一致性

先查看参考图，再区分借鉴主体、构图、风格还是配色。参考图可来自可读附件、本地文件或工具可访问的会话图；能直接使用附件时不要求用户再提供文件路径。

把可迁移特征写成具体规范：背景、2–4 个主要颜色、线条粗细、阴影或纹理、形状语言、人物表现、字体气质与留白。复杂或难以保持的参考风格可简化，但说明采用的特征，不声称精确复刻。

同篇文章固定这些规范，按每张图的信息结构变化布局。相同概念采用相同颜色与符号；颜色不能成为区分关系的唯一手段，还需标签、形状或线型。人物或对象需跨图重复出现时，记录其稳定特征，工具支持时传入基准图。

## 图形类型与构图

| 类型 | 优先表达 | 避免 |
| --- | --- | --- |
| 概念图 | 一个抽象概念的具体解释或组成 | 用多个无关图标拼凑主题 |
| 流程图 | 顺序、分支、条件与回路 | 擅加原文没有的先后或因果 |
| 对比图 | 相同维度下的差异 | 两侧使用不同标准、用面积暗示无依据的数量 |
| 框架图 | 层级、组件、包含或协作关系 | 混淆包含、依赖和时间顺序 |
| 时间线 | 原文明示的日期与演进顺序 | 编日期、把未知间隔画成精确比例 |
| 场景图 | 一个关键动作、处境或情绪 | 用装饰场景替代应解释的技术关系 |

比例服务于版式：横向适合流程和并列对比，方形适合聚焦概念，纵向适合分层或时间线。用户平台和尺寸要求优先；宽幅图不应依靠缩小文字容纳过多内容。
