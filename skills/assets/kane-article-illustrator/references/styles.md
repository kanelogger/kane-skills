# 视觉风格

图形类型负责表达关系，画风负责视觉感受，两者分开选择。用户风格和参考图优先；推荐必须适合已确定的受众与用途，不把下表当作封闭选项。

| 风格 | 可执行的视觉特征 |
| --- | --- |
| 手绘讲解 | 米白底、轻微不规则深色线条、少量柔和色块、短标签；清晰优先，不强制手写字 |
| 扁平矢量感 | 几何形状、统一描边、有限配色、清楚的连接与分区；描述画风，不承诺 SVG 文件 |
| 编辑插画 | 一个概念或隐喻、鲜明主体、克制色彩和留白，适合观点与评论 |
| 技术蓝图 | 精确节点、统一线宽、明确方向和图例；网格或纹理不能遮蔽关系 |
| 水彩叙事 | 柔和边缘、自然色彩、具体场景与情绪焦点，适合随笔和故事 |
| 深色触感编辑 | 深色留白、下部近景材质、接触与遮挡形成叙事，文字大小与方向建立编辑层级 |
| 东方水墨木刻 | 清晰深色有机脉络、手工毛边、透明淡彩与干净亮纸，图形集中于下部或一侧 |
| 静物手写独白 | 单一日常物件、自然窗光、浅底融框，已确认短句像烟一样从物件升起并穿出照片边界 |

先查看参考图，明确借鉴主体、构图、风格还是配色，不带入与文章无关的文字或事实。将选定风格写成可复用规范：背景、主要颜色、线条、质感、主体特征和留白。图内正文语言与用户要求一致；默认水印仍为精确小写拉丁文字 `kanelogger`，不随语言或风格翻译。

同篇固定这些规范，相同概念沿用相同符号和颜色；颜色之外用标签、形状或线型区分关系。重复主体记录稳定特征，工具支持时传入已通过的基准图。

构图按尺寸和展示场景调整：横向适合流程与并列对比，方形适合聚焦概念，纵向适合分层或时间线。小屏展示减少节点和文字，不靠缩小字号塞进内容；精准读数或复杂关系优先清晰结构，避免纹理和隐喻干扰。

## 深色触感编辑

用放大的主体局部进入下部画面，柔和侧光显出表面起伏，让主题相关形态彼此接触、遮挡或压叠，关系本身承载文章观点。上方保留宽阔深色空场，影像边缘与文字留出呼吸间隔；文字通过主标题、短说明与辅助信息的大小、明度和方向差建立编辑层级，侧向压暗短词可与主标题形成重量对峙。配色取自主体材质或文章情绪，保持深底、自然中间调与清亮文字的明暗秩序。

适合材质观察、设计评论及能用接触关系表达的观点文章。选用与原文一致的动作和短文案，不为了版式添加日期、栏目或无关信息；生成的摄影感画面不称为实拍。

验收近景触感与接触关系可读，深色留白保有视觉重量，标题和说明层级清楚；不能退化为主体居中陈列加普通标题，也不能把信息平均铺满。

## 东方水墨木刻

将主题转译为可识别的象征性结构，用清晰深色线描构成有机脉络，从下部或一侧斜向伸入大片亮色留白。线条保留手工毛边与轻微套印偏差，低饱和淡彩透明叠放，少量主题强调色只落在视觉停顿处。纸面细腻而洁净，文字轻薄、疏朗，不能让水墨晕染吞掉线描骨架。

适合自然观察、文化随笔、建筑与器物文章，或需要安静留白的概念插图。象征结构须能回到原文；若要表达精确关系，仍以节点和连接的清晰为先，不用装饰脉络代替事实。

验收深色脉络清楚、毛边受控、淡彩通透、亮纸干净，图形密度与留白有节奏；避免污浊纹理、烟雾化轮廓或厚重旧化。

## 静物手写独白

让一件与文章相关的日常物件独处于朴素台面，单侧自然窗光保留材质、反光与轻短阴影，主体上方留出干净浅墙。照片式画面嵌入近似墙色的浅底，以微小明度差弱化边框；手写短句从物件顶端受光处逐行升起，轻微错位、向一侧飘散，并穿出照片上沿进入外部留白。字色取物件最浓的颜色并略微压暗，细笔字保持可读。

适合生活随笔、物件记忆和个人感受文章。手写内容只用已确认文案或原文中适合的短句，不擅写独白；没有可用文案时省略正文，注明未采用手写叙事。生成画面描述为摄影感静物，不称为实拍。

验收单一物件、自然窗光和浅底融框成立；有文字时逐字核对，文字从物件升起并穿出照片边界，不变成悬浮标题或遮挡主体的大段正文。
