# 图片生成与验收

## 选择工具与生成

用户指定工具时先核实可用性和所需能力，不能满足时说明并确认替代。未指定时优先当前运行时原生工具，其次为用户已配置且授权的后端；读取当前工具说明，不假定模型名、参数、批量上限或本地保存能力。没有可用工具则保留计划与提示词，标明“图片未生成”，不安装服务或扫描凭据。

- 仅在用户已明确选择“图片和提示词都要”时调用生成或编辑工具；只说“生成插图”或“直接生成”仍须先完成入口规定的二选一，沿用计划中的其他用户要求。
- 准备完整提示词，每张都写入精确小写 `kanelogger` 的右下角水印及清晰度、安全边距、不遮挡要求；用户明确覆盖水印时使用其要求。参考图先查看，再以工具支持的实际附件、会话图或文件传入，不把不可访问路径当作输入。
- 尺寸要求对应到工具参数；未要求固定像素时可采用符合比例的原生规格并说明。工具不支持已确定规格时先确认调整，记录真实输出尺寸，不只改扩展名冒充格式转换。
- 多图先生成并查看一张，再制作其余图片；可把通过的图作为风格参考。调用方式服从工具能力和用户预算。
- 核实真实文件或工具原生结果；没有本地文件时不编造保存路径。

## 逐张查看

调用成功不能替代看图。打开实际图片，对照计划与用户要求检查：

| 检查项 | 通过条件 |
| --- | --- |
| 含义与关系 | 表达预定信息，顺序、分支、箭头、包含和对比正确，无无据暗示 |
| 文字与数据 | 标签、术语、数字、单位和日期准确，无乱码或多余文字 |
| 文字水印 | 每张默认有精确小写 `kanelogger`，右下角小号清晰，与画面协调，留安全边距，不遮主体或正文，不随图内语言翻译；普通无字或纯图模式仅有该水印，明确取消或调整时符合用户要求 |
| 可读性与规格 | 尺寸符合要求，在目标展示宽度下可读，关键元素未裁切或遮挡 |
| 整组一致性 | 配色、线条、质感和重复主体符合视觉规范 |

没有视觉查看能力时标记“已生成未验收”，不能声称验收通过。需要修正时只处理有问题的图，保留旧版本；默认初次生成后最多追加一次尝试，失败重试和修正共用此额度，用户次数或预算要求优先。

达到上限后停止该图，保留其他成功项并说明剩余问题。最终采用实际查看通过的版本；提示词、占位图或无关旧图不能充当生成结果。
