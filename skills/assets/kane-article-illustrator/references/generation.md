# 图片生成与验收

## 工具选择

1. 用户指定工具时先检查该工具当前是否可用、是否支持所需输入；不可用时说明缺项，切换用户指定工具前询问，不静默换供应商。
2. 未指定时优先使用当前运行时原生图片生成或编辑工具；其次使用用户已经配置并授权的生成后端。读取工具当下的说明和参数，不复用其他环境的模型名、包装脚本或固定批量上限。
3. 没有可用工具时仍保存计划和提示词，逐图标记“待工具”，明确报告图片未生成。请用户选择可用工具或稍后继续，不安装另一套服务、不索取或扫描密钥。

这套工具选择规则内置于技能，不依赖另一个生图技能、仓库环境文件或私人配置。运行时如要求读取其工具专用指引，遵守该要求；这里不提供虚构的备用 CLI。

## 生成

- 只做方案或提示词的任务不调用生图工具，也不为其索取生成凭据。
- 每次调用前已保存最终提示词。参考图先查看，再通过工具支持的附件、会话图或本地路径传入；声明其用途，不把不可访问的路径或“见上一张”当作实际输入。无法传入时描述可见风格并说明限制，主体或构图必须依赖原图时先补齐输入。
- 多图先生成一张基准图并查看，再制作其余图片。不要求用户额外批准已经确定的方案；只有需改变图意、数量或关键风格时才补问。
- 生成顺序与并行方式服从工具能力和用户预算。独立图可在基准通过后批量处理，需要共享主体参考的图保持依赖顺序。
- 工具输出有实际文件时核实文件可读，记录真实格式与路径；不只改扩展名冒充格式转换。没有必要不压缩、不裁切、不二次转码。
- 工具只返回原生图片结果时按工具规则交付该结果，记录结果标识和本地文件是否可用。没有实际文件时不编造保存路径，不先写 Markdown 图片引用。

## 看图检查

调用成功、收到文件名或提示词声称正确，都不能代替查看成图。逐张用当前运行时可用的视觉能力打开实际图片，并记录：

| 检查项 | 通过条件 |
| --- | --- |
| 文章含义 | 主体与关系表达了计划中的一个具体信息，无无关暗示或事实补写 |
| 文字与数据 | 标签、术语、数字、单位、日期与文章一致，无乱码、重复或多余文字 |
| 结构关系 | 顺序、分支、箭头、包含及对比维度正确，示意与定量表达区分清楚 |
| 可读性 | 计划展示尺寸下信息清楚，关键元素没有被裁掉或相互遮挡 |
| 视觉一致性 | 配色、线条、人物或主体和整组规范一致 |
| 文件与引用 | 声明已保存的图片确实存在且能打开，记录的扩展名符合实际格式 |

涉及事实的缺陷不能按“风格问题”忽略。没有视觉查看能力时保留图片并标记“已生成，未验收”，说明原因；不声称完整出图已验收完成。

## 修正与停止

每张初次生成后默认最多追加一次尝试，工具失败重试与成图修正共享此额度；用户给出的次数或预算优先。先判断问题能否通过明确修改解决，再花费额外调用。不将明显无关的结果反复作为参考传入。

编辑使用工具支持的原图输入；重画使用完整提示词和同一视觉规范。保留旧图、新图及对应提示词，只将实际查看通过的版本设为交付版本。不要遮盖错误文字后声称原图已正确。

达到次数或预算上限时停止该图，保留其他成功项，说明失败原因、当前最佳候选和后续所需决定。调用不返回、授权缺失或工具不可用时如实报告，不能用其他无关图片、占位图或提示词文件冒充已生成的插图。
