# 提示词编写

每张图一份完整提示词，不依赖“同上”或未传入的上下文。把已确定的受众、用途、风格、尺寸和水印要求落实为绘制要求；确认过程和整批管理信息留在计划中。每份独立提示词都完整写出水印，不能只在总说明中声明。

## 逐图模板

按实际内容填写，不把字段名、内部编号或色值画进图片。图内正文的语言和精确内容单独声明；提示词语言按工具能力选择。普通“无字”“纯图”或“只准中文”等正文限制不取消或翻译默认水印；“只允许指定文字”等限制应把水印列为明确例外。用户明确要求无水印或修改水印时，以其要求替换水印项。

```text
目的：帮助什么读者理解什么信息。
内容：具体主体、动作、必须表达的关系。
构图：图形类型、分区、阅读顺序、留白，按展示场景控制信息密度。
可见正文与数据：逐项列出；普通无字或纯图模式写“除下述水印外无文字”，不额外生成标题或长段落。
文字水印：精确小写拉丁文字“kanelogger”，右下角，小号但清晰，与画面协调，保留安全边距，不遮挡主体或正文，不翻译。
视觉：完整写出统一配色、线条、质感和主体特征。
规格：已确定的宽高比、必要像素尺寸及边距。
参考图：实际可访问的图片及借鉴用途，没有则省略。
关键限制：本图容易出现的错误关系或无依据暗示。
```

提示词旁附文章锚点和本图验收要点；工具只接收绘制内容及必要参考图。独立提示词文件可用 `01-cache-flow.md` 这样的稳定编号和主题命名。

## 按内容写准关系

| 图形类型 | 必须写清的内容 |
| --- | --- |
| 概念图 | 主体、组成和视觉映射；隐喻不当作事实证据 |
| 流程图 | 节点、每条有向连接、条件与分支；不擅补原文未给出的业务逻辑 |
| 对比图 | 两侧使用相同维度与相当视觉权重；无定量依据不画比例柱或百分比 |
| 框架图 | 区分包含、依赖、协作与顺序；不同线型有图例 |
| 时间线 | 原文日期和顺序；未知时间不画成精确比例 |
| 场景图 | 一个视觉焦点、具体动作、环境与情绪，不把小标题堆成文字海报 |

专有名词、数字、单位、日期与文章逐项核对。标签尽量短；核心文字、公式或关系难以可靠绘制时简化或建议精确制图，不能用近似结果冒充准确表达。用户要求示意数据时明确标为“示意”。

单张修改保留图意、已确定的规范与正确内容，明确需改变的元素和期望关系。支持编辑时传入实际原图，否则使用完整提示词重画；保留旧版本。
