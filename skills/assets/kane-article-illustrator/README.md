# kane-article-illustrator

为已有文章规划插图、编写提示词或生成图片。从读者需要理解的信息出发，集中补齐关键要求，再把你的回答落实到选点、构图、视觉风格和交付结果中。

每张图片（含系列中的每张）和每份独立完整提示词默认带文字水印 `kanelogger`：精确小写拉丁文字，置于右下角，小号清晰，opacity `0.6`（60% 不透明），与画面协调、不影响整体，留安全边距，不遮主体或正文。水印不随图内语言翻译；普通无字或纯图模式仍保留该水印。你明确要求无水印，或修改文字、位置、不透明度等设置时会遵从，无需为默认水印额外确认。

## 使用

在支持技能的 Agent 中按名称调用；Codex 中可输入 `$kane-article-illustrator`。

```text
给这篇文章配图，先问清交付形式和制作要求。
只写 2 张提示词：面向开发新手，放技术博客，手绘讲解风，横向 3:2。
图片和提示词都要，共 2 张图：受众是产品经理，用于内部报告，扁平矢量感，1536×1024。
先做配图方案，列出位置、图意和推荐风格，等我确认再生成。
图片和提示词都要，未指定的制作要求你来定，不用问我；先列明采用值。
沿用上次方案，只重做第 2 张图；完成后另存带图 Markdown。
```

## 会问什么，答案用在哪里

提供文章正文或可读文件，可附参考图。只有标题或摘要时需要补正文；节选只处理已提供部分。

| 要求 | 对结果的影响 |
| --- | --- |
| 仅提示词，或图片和提示词都要 | 明确是否调用生图工具；先做方案时停在方案阶段 |
| 受众、已有知识与使用渠道 | 决定术语、解释深度、文字密度和可读性 |
| 风格或参考图 | 决定配色、线条、质感、主体表现和整组一致性 |
| 尺寸 | 宽高比决定布局；需要固定像素时明确规格，也可接受推荐 |
| 数量与位置 | 决定选点及信息拆分，不机械地每章一图 |

仅询问会影响结果的缺项，尽量集中一轮，已有答案不重复问。提示词也会受这些要求影响，因此不会仅因“不生图”跳过关键问题。只做探索方案时可先列建议；如果你明确说“你来定”“按推荐”或“不用问我”，会对受委托的制作要求采用并说明合理值，不要求特定口令；一般委托不代替交付形式的选择。

生成前会明确问：“你需要哪种交付形式：① 仅提示词；② 图片和提示词都要？”即使你说“生成插图”“实际生成图片”或“直接生成”，也会先让你选择；已经明确选过则不重复问。这个问题会与其他缺项集中一轮提出，等你回答后再定稿提示词或生图。仅提供比例且没有固定像素要求时，可说明采用工具原生规格。用户未回复不等于选择或接受推荐；要求“等我确认”时会等待。

收到答案后会完善计划与逐图提示词。例如面向新手减少未经解释的术语，面向小屏减少节点和长标签；不会只把答案留在需求表里。

## 交付

| 形式 | 产物 |
| --- | --- |
| 先做方案 | 需求摘要、配图位置、图意与视觉建议，到此停止 |
| 仅提示词 | 计划和可独立使用的逐图提示词，不调用生图工具 |
| 图片和提示词都要 | 计划、独立提示词、真实图片或工具原生结果，以及逐张查看结论 |

默认输出到文章同级 `illustrations/<文章名>/`；粘贴正文用工作目录下 `illustrations/<主题短名>/`。按范围保存 `plan.md`、`prompts/` 和真实 `images/`，不强制复制正文，也不创建图片占位文件。续做保留旧版本，仅处理指定项。

仅在你要求时把通过验收的本地图片插入 Markdown，默认另存 `<文章名>-illustrated.md`，保留原稿和已有图片，并检查相对引用。

## 依赖与限制

技能可单独复制使用，无自带脚本。实际出图需要运行时已有生成工具及其授权；优先尊重指定工具，否则选择可用原生工具，不自动安装后端或扫描密钥。尺寸、格式和参考图能力以工具为准，“矢量感”不保证 SVG 文件。

生成后逐张检查含义、文字、关系、规格、一致性和采用的水印要求；工具支持水印不透明度设置时实际采用 `0.6`，你明确修改时采用你的值。默认每张初次生成后最多追加一次尝试，用户预算或次数要求优先。没有工具会交付可完成的计划与提示词并说明图片未生成；无法看图则标记“已生成未验收”。
