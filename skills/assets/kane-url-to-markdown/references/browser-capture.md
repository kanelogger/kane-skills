# 浏览器获取

用于动态页、登录页、用户指定浏览器，或网页读取工具没有取得完整正文的情况。

1. 用户指定工具 / 会话时沿用；否则按 **ego-browser → browser-skill → 当前运行时其他浏览器工具** 选择可连接的工具。先读取所选工具的现有接口和授权规则，在自己的任务页打开 URL，遵守用户接管状态；不借用或导航用户已有页面来绕过授权。
2. 等正文可见，必要时滚动加载。登录、验证码和付费确认交给用户处理，交回控制权后重新观察。记录当前最终 HTTPS URL，不把可访问页面的快照当成已取得全文。
3. 已打开的会话直接交给包内脚本，不复制浏览器采集代码：

   | 工具 | 调用 |
   | --- | --- |
   | ego-browser | 将 TaskSpace 的 `p1` 打开到目标页，再运行 `${BUN_X} "{baseDir}/scripts/main.ts" '<最终 URL>' --ego-space <TaskSpace ID> --output '<新文件.md>'` |
   | browser-skill | 使用 Agent Window 的任务页，再运行 `${BUN_X} "{baseDir}/scripts/main.ts" '<最终 URL>' --bsk-session <session_id> --output '<新文件.md>'` |

   脚本只读取当前任务页，不创建、导航或关闭会话；地址改变或控制状态不可用时停止，由 Agent 重新观察和处理，不自动绕过或切换会话。
4. 其他浏览器工具可获取任务正文 HTML 和必要公开元数据，保存为唯一的 UTF-8 临时文件，再用 `--html '<临时文件>'` 转换。只取正文，不序列化含脚本、表单、凭据或应用状态的完整原始页面。
5. 核对产物与可见正文，按所选工具规则关闭或归还任务页，删除临时文件。多篇 `article` 卡片、iframe、影子 DOM、编辑器和 Canvas 不保证由普通 DOM 提取覆盖；发现抓错区域或缺失时按工具实际能力读取目标内容并披露范围，不补写。

包内 HTML 转换依赖仅在此分支安装；图片保留远程链接，签名、登录或防盗链图片可能无法在 Markdown 阅读器中显示。
