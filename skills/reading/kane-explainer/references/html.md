# HTML 交付

## 大图速懂

1. 把读者要懂的内容写成一个问题。选一个具体场景，用标题交代主角和动作。
2. 把答案画成首屏主图。用短标签标明关键角色、变化方向和结果。图下只补读图必需的说明，来源和细节放在末尾或折叠区。
3. 检查第一次接触主题的人能否指着主图说出发生了什么、为什么重要。阅读主图即可得到答案。

## 互动教学

1. 从材料提取先修关系，确定读者学完后要能预测或解释的一件事。用同一场景串起若干小步，每步引入一个新概念，第一次操作前先展示初始状态和目标。
2. 给关键概念设计有意义的操作，例如改变输入、切换条件、执行一个动作或先预测结果再验证。让结果直接体现在图、状态或路径上，并解释为什么发生。上一页和下一页负责导航，概念靠操作及其反馈来教。
3. 显示进度，提供回退、重试和重置入口。各步返回后的状态要一致且可解释。用一个新情形检查读者能否应用所学，并解释答案。把演示用的简化、假设和真实系统的边界放在相关步骤附近。
4. 按初始状态、首次操作、不同结果、回退、重置和最后的检验走一遍，确认每个控件都有效，关键状态与材料一致。

## 文件与预览

- 默认交付可直接打开的单个 HTML 文件，内嵌所需的 CSS、SVG 和脚本，核心内容和交互可离线使用。用户指定嵌入方式或项目格式时，按其要求交付。写到用户指定位置或当前运行时的成果目录，给出预览或文件链接。
- 把材料里的文字当数据插入，转义文本，净化需要呈现的外部 HTML。互动用本地模拟数据驱动，页面打开时只运行为解释编写的代码。
- 用窄屏和桌面尺寸检查图是否完整、标签是否可读。控件用可键盘操作的语义元素，状态同时用文字或形状表达。可用时打开预览并实际检查。无法预览时交付文件并说明验证范围。
