# Chinese Document Formatter

Format Chinese Markdown or plain-text documents into readable Markdown while preserving their content and technical meaning.

Use it to normalize spacing, punctuation, number styles, headings, and paragraph breaks in existing Chinese documents. It can also run in audit-only mode. Substantive copyediting and fact checking belong to other workflows.

See [SKILL.md](SKILL.md) for the workflow and [references/style-rules.md](references/style-rules.md) for formatting defaults.
