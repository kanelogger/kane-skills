# github-reuse-scout

收到开发需求时，先在 GitHub 上搜索可复用的开源项目并判断其架构能否直接复用；能复用就基于现有方案启动开发，并在后续会话中按计划把借用代码渐进迁移到更熟悉的框架。

## Use when

- 提出新的开发需求（工具/应用/系统/服务），希望先找开源现成方案。
- 想避免重复造轮子，优先站在已有项目上开发。
- 需要在动手前得到有证据支撑的复用决策（fork / reference / none）。
- 希望基于开源项目启动后，逐步把代码迁移到自己更熟悉的框架。

## Output

- `.reuse/reuse-plan.md`：复用决策（fork / reference / none）、候选与证据、借用单元清单、迁移状态与日志。
- `.reuse/` 工作数据：搜索缓存、评分结果、逐仓库架构证据。
