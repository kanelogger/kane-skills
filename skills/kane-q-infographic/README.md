# kane-q-infographic

`kane-q-infographic` 用来把文章、数据、流程或复杂概念转成结构清晰的信息图。它会根据内容选择合适的阅读顺序、信息层级和视觉结构；需要讲解角色时优先使用 Kane Q。

## 适用场景

- 把流程、时间线、比较、框架或数据关系做成信息图。
- 为文章或社交内容制作一张可独立阅读的知识图。
- 用简短标签和视觉层级解释复杂概念。

## 输出

- 已保存的信息图提示词。
- 经过事实、文字可读性、阅读顺序和视觉一致性检查的信息图图片。

## 使用示例

```text
Use $kane-q-infographic to turn this process into a vertical infographic:

这里粘贴流程、文章或数据。
```

直接指定信息结构：

```text
Use $kane-q-infographic to create a 4:5 comparison infographic from these two approaches.
```
