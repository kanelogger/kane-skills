# merge-drafts

把多份稿件合并成一篇成稿：先选出最强的一份作为底稿，再吸收其余稿件中有用的材料。

## 适用场景

- 用户提出合并稿件、合稿、统稿、整合版本，或想把多篇文章草稿合成一篇。
- 多份源文件或粘贴的稿件写的是同一个目标稿件。
- 产物需要保留最佳结构，同时补齐缺口、消除重复、改善衔接。

## 输出

- `merged_article.md`：合并稿。
- `merge_report.md`：底稿选择、各稿贡献、取舍、统计与未决问题。

至少提供两份稿件，可附 `analysis.md`。默认写入稿件目录下的 `merged/`；多目录或粘贴输入用指定位置或当前项目。目录已存在时另用编号目录，保留源稿和旧产物。证据无法裁定且影响主张的冲突需用户决定；未解决前仅交付带标记的草稿，不声称可以发布。

## 公开说明

本包只包含流程说明，稿件由使用者作为任务输入提供。

中文文风规范直接写在本技能内，因此整个包被复制或分发后仍可独立使用。原文保真要求优先，例外情况需记录。
