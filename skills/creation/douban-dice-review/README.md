# douban-dice-review

用六个理论骰子生成一篇简短的中文豆瓣风格影评。

在 Codex 中输入 `$douban-dice-review` 显式调用。

## 适用场景

- 用户要求豆瓣影评、骰子影评、六个骰子写影评，或按理论关键词写的影评。
- 影评应当紧凑、风格化，由随机抽到的理论关键词塑形。
- 必要可以轻度核查电影事实，但核心产物是那六句影评。

## 输出

- 由 `scripts/roll_dice.js` 生成的一次投骰汇总。
- 按骰子顺序写成的一份中文六句影评，固定不加编号，每句显式包含对应关键词。

## 公开说明

提供片名或电影素材后才开始；脚本无第三方依赖，可用 Node.js、Bun 或 `npx -y bun` 运行。脚本产生随机结果并输出可核对的点数和关键词；无法运行时明确标为手动示例，不声称执行过随机算法，也不编造电影事实。
