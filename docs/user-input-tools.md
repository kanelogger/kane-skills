# user-input-tools

本仓库的技能会被多种 agent 运行时加载（Claude Code、其他 agent、裸 CLI）。每种运行时用来向用户提问的 API 都不一样。本文是这份**工具选择规则**的正本（canonical），每个技能都要遵循它，以保证技能的可移植性。

## 工具选择（按优先级）

1. **优先用内置的用户输入工具**：如果当前 agent 运行时提供了这类工具——比如 `AskUserQuestion`、`request_user_input`、`clarify`、`ask_user`，或任何等价工具。
2. **回退到纯文本**：如果没有这类工具，就输出一条带编号的纯文本消息，请用户针对每个问题回复所选的编号或答案。
3. **批量提问规则**：
   - 如果工具支持**一次调用提多个问题**（例如 `AskUserQuestion`）：**把所有适用问题合并成一次调用。不要拆成多次调用。**
   - 如果工具**一次调用只能问一个问题**（例如单次提问的 `clarify`）：按优先级顺序，**一次问一个问题**。

## User Input Tools（用户输入工具）

每个用到交互式用户输入的 `SKILL.md`，都要包含**恰好一个** `## User Input Tools` 章节（通常放在开头附近，紧跟导言之后），并把本规则**内联**（原文照抄）进去。不要从 `SKILL.md` 链接到本文——技能是自包含的（见 [AGENTS.md → 技能自包含](../AGENTS.md)）。本文是作者侧的正本；请把它的正文复制进每个 `SKILL.md`。此后，这条规则约束该技能及其 `references/` 文件中的所有用户输入交互。

技能中其他地方提到某个具体工具（例如 `AskUserQuestion`）时，这些只是**具体示例**——其他运行时中的 agent 应套用上述规则，替换为本地等价工具。工具特有的参数（例如 `header:`、`multiSelect:`）仅作示意；没有这些参数开关的运行时可以省略它们。
